# 🎬 Site de Filmes — TMDB API

Este é um projeto **em desenvolvimento** criado com o objetivo de **praticar React** e o **consumo de APIs**, utilizando a API gratuita do **TMDB (The Movie Database)**.

O projeto faz parte do meu processo de evolução como desenvolvedor **Front-end**, aplicando conceitos fundamentais do React na prática.

---

## 🚀 Tecnologias utilizadas

* **React**
* **Vite**
* **JavaScript (ES6+)**
* **CSS**
* **API TMDB (The Movie Database)**
* **React Router DOM**

---

## 📌 Funcionalidades implementadas até o momento

* ✅ Listagem de filmes populares
* ✅ Busca de filmes pelo nome
* ✅ Página de detalhes do filme
* ✅ Consumo de API externa (TMDB)
* ✅ Loading durante requisições
* ✅ Tratamento básico de erros
* ✅ Navegação entre páginas (rotas)
